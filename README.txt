HOW TO DEPLOY ON NETLIFY (Free — recommended):
  1. Go to netlify.com and create a free account
  2. Click "Add new site" → "Deploy manually"
  3. Drag and drop this entire folder
  4. Your site is live instantly at a netlify.app URL
  5. Go to Site Settings → Domain to connect your custom domain

HOW TO DEPLOY ON ANY WEB HOST:
  1. Upload all files maintaining the folder structure
  2. Ensure index.html is in the root directory
  3. css/ and js/ folders must be in the same directory as the HTML files

PAYMENTS (Stripe — recommended):
  1. Create account at stripe.com
  2. Create products: "Member - $47/month" (recurring) and "Coaching" (one-off)
  3. Generate Payment Links for each
  4. Replace the "Become a member" and "Apply for Coaching" button
     href values in index.html with your Stripe payment link URLs

COMMUNITY PLATFORM (Skool — recommended):
  1. Create account at skool.com
  2. Set up your community with the 7 areas as groups
  3. Replace the "Join free today" button href with your Skool community URL
  4. For paid tier: connect Stripe → Skool via Zapier for auto-access
